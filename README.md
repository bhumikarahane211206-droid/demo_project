# CampusRide — Student Travel Booking (Demo)

CampusRide is a demo, responsive travel booking website tailored for college students. This repository contains a vanilla HTML/CSS/JS prototype using LocalStorage for demo data persistence.

Features included in this demo:
- Landing page with hero, features, testimonials and FAQ
- Student registration (local demo)
- Ride search & filters
- Booking flow with QR ticket generation (Google Charts API)
- Ticket download/print via browser
- Responsive layout and glassmorphism UI

Tech stack:
- HTML5, CSS3, JavaScript (vanilla)
- LocalStorage for demo persistence

How to run:
1. Open `index.html` in your browser (recommended to serve via a static server for proper local behavior).

Example using Python's simple server:
```bash
cd /workspaces/demo_project
python3 -m http.server 5500
# then open http://localhost:5500 in your browser
```

Notes:
- This is a front-end demo. Replace LocalStorage with Firebase/Node.js backend for production.
- QR code uses Google Charts API for demo purposes.
